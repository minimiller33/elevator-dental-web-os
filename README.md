# Elevator Dental OS

Primera landing de venta para Elevator Dental OS: una infraestructura web viva para clinicas dentales.

## Desarrollo

```bash
npm install
npm run dev
```

## Validacion

```bash
npm run lint
npm run build
```

## Antes de produccion

- Confirmar que `hello@theelevator.io` sea el correo comercial definitivo.
- Verificar que los datos de Clinica DrDiente comparen periodos equivalentes de cuatro meses en Google Search Console.
- Conectar el formulario final al CRM de Elevator.
- Sustituir el isotipo reconstruido en SVG por el vector maestro de la identidad cuando este disponible en el repositorio.
